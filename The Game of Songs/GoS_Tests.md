# GoS 测试用例文档

> 配套程序：`GoS_FightCalculation.cpp`（g++ -std=c++17 -Wall -Wextra -O2 编译；全部用例通过，含式微 W1–W8、蓁蓁 ZZ1–ZZ7、白露/为霜 LU1+SL1–SL8、时间旅行交互 T4–T5）
> 本文档记录所有结算测试用例，便于查看与回归。

## 0. 如何阅读

- 每个用例给两个机器人的**纸带**（循环招式序列），记为 `[id1, id2, ...]`。
- **输入格式**（程序固定）：先 `T1`、再 T1 个招式 id、再 `T2`、再 T2 个招式 id。招式可用 `*` 后缀附加「为霜」，如 `102*` = 有 + 1 次为霜、`102**` = 有 + 2 次为霜、`1000*` = 仅 1 次为霜。
- **结果记号**：
  - `R1w rN` = Robot1 在第 N 回合获胜（对手生命归 0）；
  - `R2w rN` = Robot2 在第 N 回合获胜；
  - `never` = 双方在 `10 × T1 × T2` 回合内无人落败（程序判为「可能永远不结束」）。
